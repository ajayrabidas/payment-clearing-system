Issues Faced:

# Issues Faced and Solutions

1. **MySQL Workbench compatibility warning with MySQL 9.x**
   Solution: Continued temporarily using “Continue Anyway” and recommended using stable versions like MySQL 8.0 + Workbench 8.0 for Spring Boot compatibility.

2. **Spring Boot 2.7 not visible in Spring Initializr**
   Solution: Generated a Spring Boot 3 project first, then manually changed `pom.xml` to Spring Boot 2.7.18 and updated Java version.

3. **Kafka startup failed with ZooKeeper timeout**
   Solution: Started ZooKeeper first using `zookeeper-server-start`, then started Kafka in a separate terminal.

4. **Spring Boot main class not found**
   Solution: Verified package structure, recreated IntelliJ run configuration, and rebuilt the project using Maven.

5. **Spring Boot 3 incompatible with Java 8**
   Solution: Either downgrade to Spring Boot 2.7 for Java 8 or fully migrate to Java 17 for Spring Boot 3.

6. **Maven using wrong Java version**
   Solution: Updated `JAVA_HOME`, configured IntelliJ Project SDK/Maven JVM to Java 17, and reloaded Maven.

7. **Need to maintain both Java 8 and Java 17**
   Solution: Installed both JDKs and configured project-specific SDKs in IntelliJ while keeping Java 17 as default.

8. **Environment variables not reflecting immediately**
   Solution: Restarted IntelliJ and terminal sessions after updating `JAVA_HOME` and `PATH`.

9. **Set Java 17 globally across Windows**
   Solution: Updated `JAVA_HOME` and `PATH` to point to Java 17 and removed old Java 8 entries.

10. **Unable to start/open MySQL server and Workbench**
   Solution: Started MySQL service from `services.msc` and connected through MySQL Workbench using localhost and port 3306.

11. **Where to place SQL files in Spring Boot project**
   Solution: Added `schema.sql` and `data.sql` under `src/main/resources` for automatic Spring Boot execution.

12. **TestNG dependency missing during build**
   Solution: Replaced `org.testng.annotations.Test` with JUnit 5 `org.junit.jupiter.api.Test`.

13. **Application required `mvn clean install` before every run**
   Solution: Fixed IntelliJ SDK, Maven JVM, compiler settings, and invalidated IntelliJ caches.

14. **OpenJDK Platform Binary firewall popup appearing repeatedly**
   Solution: Allowed Java executables permanently in Windows Firewall under private networks.

15. **Placement of `GlobalExceptionHandler` class**
   Solution: Created a dedicated `exception` package and added `@RestControllerAdvice`.

16. **Swagger UI showing Whitelabel Error Page**
   Solution: Replaced old Swagger dependency with Spring Boot 3 compatible `springdoc-openapi-starter-webmvc-ui`.

17. **Where to create Dockerfile in Spring Boot project**
   Solution: Created `Dockerfile` in the project root alongside `pom.xml`.

18. **Docker daemon connection failure**
   Solution: Started Docker Desktop and verified Docker engine using `docker version`.

19. **Docker build failed because Dockerfile not found**
   Solution: Created correctly named `Dockerfile` without `.txt` extension in project root.

20. **Docker image not found while running container**
   Solution: Built the Docker image successfully using `docker build -t payment-system .`.

21. **Docker COPY failed because JAR file name mismatched**
   Solution: Verified actual JAR name inside `target/` and updated Dockerfile COPY command accordingly.

22. **Docker container failed due to Java 8 runtime**
   Solution: Changed Docker base image from Java 8 to Java 17 using `eclipse-temurin:17-jdk`.

23. **Spring Boot container unable to determine Hibernate dialect**
   Solution: Added proper datasource URL, MySQL dialect, and replaced localhost with `host.docker.internal`.

24. **Spring Boot tests failing during Maven build**
   Solution: Skipped tests temporarily using `mvn clean package -DskipTests`.

25. **Git push rejected because remote repository had existing commits**
   Solution: Pulled remote changes using `git pull origin main --allow-unrelated-histories` and then pushed successfully.
